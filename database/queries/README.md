# SQL Queries — Required Inquiries

This folder contains the 6 required SQL queries for the project.
Each query is in its own file for clarity.

---

## Query Files

| File | Query Description |
|------|------------------|
| `q1_below_average_efficiency_by_manufacturer.sql` | Manufacturer with most below-average readings |
| `q2_sites_no_inspections_last_month.sql` | Sites with no inspections last month |
| `q3_technician_max_inspections_last_month.sql` | Top technician by inspection count |
| `q4_units_no_replacements_last_month.sql` | Power units with no replacements |
| `q5_components_per_site_last_month.sql` | Components installed per site |
| `q6_technician_profile_and_units.sql` | Technician profile and total inspected units |

---

## How to Test a Query

1. Make sure the DDL scripts in `/database/ddl/` have been run first
2. Make sure sample data has been inserted
3. Open the query file in SSMS
4. Press F5 to execute
5. Verify the result matches the expected output described in the file's comments
