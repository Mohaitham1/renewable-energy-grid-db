# renewable-energy-grid-db# ⚡ Renewable Energy Grid & Maintenance Network

> University Database Project
> Faculty of Computers and AI — Cairo University

---

## 📋 Project Overview

A database application for a green energy corporation that manages a network 
of power-generation assets across rural landscapes.

The system tracks:
- Energy sites with GPS coordinates and terrain types
- Power units (wind turbines and solar arrays)
- Field technicians and their certifications
- Inspection rounds and scheduling
- Efficiency readings and performance monitoring
- Component replacements and spare parts inventory
